Guide

How it works

Everything you need to publish press materials on the press kit website.
  1. Pick a brandThe brands on the left are the brand pages of the website. Each brand page lists its documents.
  2. Create a documentClick + New document, give it a title, choose the category (Photos, Videos, Documents, Embargo) and, if you want, a short description. You can already drop the files or a whole folder in the same window.
  3. Add the filesDrop files or folders in the box, or use Choose files / Choose folder. There is no size limit. Folders keep their sub-folders: journalists will see one section per folder.
  4. PublishA new document is a Draft: nobody can see it. When files and details are ready, click Publish. It appears on the brand page within a few seconds.

Good to know

  • Files added to a live document are online immediately. Changes to title, category or description go live when you click Save changes.
  • A file with the same name replaces the old one. Use Rename to change a name (the extension is kept).
  • Unpublish hides a document without deleting anything. Delete document removes it and its files for good.
  • Thumbnails and previews are created in your browser while uploading: keep the page open until the upload is complete.
  • If an upload fails (for example the connection drops), click Retry failed.

Categories

  • Photos, Videos, Documents: shown under the matching filter on the brand page.
  • Embargo: the document gets the “Under Embargo” badge. Publish it only when the embargo allows it.
  • Technical sheet: tick it for spec sheets. The document gets a “Technical sheet” badge and appears under the “Technical sheets” filter.

What journalists see

  • A gallery with previews of photos, videos and PDFs, a Download button on every file, Download folder for each folder and Download all as a ZIP.
  • Originals are always delivered at full quality.
  • Use View on website on a live document to check it.

Press contacts

  • Under Press contacts you can add, edit and remove the press office contacts shown on the website.
  • New contacts are drafts until you publish them.

Something went wrong?

  • “Webflow is not responding”: the website’s content system is temporarily unavailable. You can still add or remove files; try again in a few minutes for everything else.
  • “Session expired”: sign in again, nothing is lost.
  • Folders not linked to a document (at the bottom of a brand page): files uploaded without a document. Create a document from them, or delete them.
